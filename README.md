# МС-АСП — цифровой двойник

Интерактивная 3D-визуализация проекта «Механизм строповки и автоматизированная система подъёма крупногабаритных модулей» (УрФУ, 2026).

**Открыть:** https://kk228m10-sys.github.io/ms-asp-digital-twin/

Что показывает:
- кран-балка 8 т на подкрановой эстакаде, электроталь, траверса 4800×2500 с подвижными каретками;
- 6 датчиков усилия в стропах, инклинометр, абсолютный энкодер, лазерные дальномеры X/Y, ИК-барьеры, маяк и сирена;
- автоматический цикл ПЛК ОВЕН ПЛК210 из 11 этапов, модули 1 / 3 / 5 / 8 т;
- гашение раскачивания: ZVD по модели двух масс, ZVD по длине каната, без подавления;
- проверка защит: перегруз, дисбаланс, наклон, слабина, человек в зоне, потеря связи, обрыв датчика.

Управление: кнопки пульта мышью или клавиши R/F — подъём/опускание, W/S — мост, A/D — тележка.
Нужен браузер с WebGL (Chrome, Edge, Firefox) и интернет — библиотека three.js загружается с CDN.

Автор раздела: Кенибаев Касым (автоматизация).
